# labs

Time-boxed experiments. Nothing here is production code; treat each subfolder as
a sketch that can be thrown away.

## Layout

```
labs/
  YYYY-MM/
    <experiment-slug>/
      README.md   # goal, links, results
      ...         # whatever the experiment needs
```

- One folder per calendar month (e.g. `2026-05/`).
- Inside, one folder per experiment, kebab-case slug.
- Each experiment's `README.md` states the goal, references, and what was
  learned. Capture dead ends too — that's the point of labs.
